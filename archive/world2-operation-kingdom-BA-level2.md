## Level 2-1-1: Pirate Numbers Introduction

### Story Context
> 🏴‍☠️ Pirates count differently! They only use 5 fingers (0-4), so they "regroup" at 5 instead of 10!

### Teaching
```
[MERLIN EXPLAINS]
"In our world, we use BASE 10 - we have 10 digits (0-9).
But pirates use BASE 5 - they only have 5 digits (0-4)!

In Base 5:
0, 1, 2, 3, 4... then what?
Instead of '5', pirates write '10' (meaning 1 group of five, 0 ones)

Pirate 10 = Our 5
Pirate 11 = Our 6 (1 five + 1 one)
Pirate 12 = Our 7
..."
```

### Challenge
```
[PROBLEM 1]
In pirate numbers (base 5), what comes after 4?
A. 5    B. 10    C. 14
Answer: B (10 in base 5)

[PROBLEM 2]
What is pirate number "13" in our regular numbers?
(1 five + 3 ones = 5 + 3 = 8)
Answer: 8

[PROBLEM 3]
How would a pirate write "7" in pirate numbers?
(7 = 1 five + 2 ones = 12 in base 5)
Answer: 12
```

### Why This Matters
```
🧠 Big Idea:
Understanding different bases helps us TRULY understand 
why our number system works the way it does!

When you understand base 5, you understand base 10 better.
```

## Level 2-1-5: Place Value Puzzles

### Challenge (AoPS Style)
```
[PROBLEM 1]
I'm a 3-digit number.
My hundreds digit is 5.
My tens digit is 2 more than my ones digit.
My digits sum to 13.
What number am I?

Let ones = x, tens = x + 2, hundreds = 5
x + (x + 2) + 5 = 13
2x + 7 = 13
2x = 6
x = 3

So: ones = 3, tens = 5, hundreds = 5
Number: 553

Wait, let me check: 5 + 5 + 3 = 13 ✓
And tens (5) is 2 more than ones (3) ✓
Answer: 553

[PROBLEM 2]
Use the digits 4, 5, 6, and 7 once each.
Write a 4-digit number as CLOSE to 5,000 as possible.

Options near 5,000:
- 5,467 → 467 away from 5,000
- 5,476 → 476 away
- 5,647 → 647 away
- 4,765 → 235 away from 5,000!
- 5,467 vs 4,765: 4,765 is closer!

Actually: 5,467 - 5,000 = 467
        5,000 - 4,765 = 235
So 4,765 is closer!

Answer: 4,765
```

## Level 2-7-1: Sum and Difference Problems

### Teaching
```
[MERLIN'S METHOD]
"When you know the SUM and DIFFERENCE of two numbers..."

Ben and Frank have 49 coins together. (SUM = 49)
Ben has 5 more coins than Frank. (DIFFERENCE = 5)
How many does Frank have?

Method: 
If Frank has F coins, Ben has F + 5 coins.
F + (F + 5) = 49
2F + 5 = 49
2F = 44
F = 22

Frank has 22 coins. (Ben has 27)
```

[PROBLEM 3 - CHALLENGE]
Three friends have 63 stickers in total.
Anna has 7 more than Bob.

How many does each person have?

3C + 17 = 63
